# 方法对照矩阵

返回 [[3D结构透视研究/00 3D结构透视研究 Dashboard|研究 Dashboard]]

这些族会组合，不是互斥产品模式。保形状、保原位、保拓扑、保度量、保单投影是不同要求。

| 方法 | 显露机制 | 保留什么 | 主要代价 |
|---|---|---|---|
| [[3D结构透视研究/方法/01 透明、转移函数与OIT\|透明、转移函数与OIT]] | 透明贡献、选择性淡化 | 保位置和投影 | 混色、层序；未保证全可辨 |
| [[3D结构透视研究/方法/02 隐藏线、轮廓与语义着色\|隐藏线、轮廓与语义着色]] | 隐藏边、光晕、ghosting | 保位置 | 线条拥挤，交叉语义不清 |
| [[3D结构透视研究/方法/03 平面、目标驱动与非平面剖切\|平面、目标驱动与非平面剖切]] | 删除遮挡区域 | 保目标原位 | 被切部分缺失 |
| [[3D结构透视研究/方法/04 局部X-ray与体数据透镜\|局部X-ray与体数据透镜]] | 局部窗口或排斥场 | 保焦点对应 | 窗口外仍隐藏；部分变形 |
| [[3D结构透视研究/方法/05 层级、紧凑与多透视爆炸图\|层级、紧凑与多透视爆炸图]] | 部件/楼层移开 | 通常保部件形状 | 失去真实接触和距离 |
| [[3D结构透视研究/方法/06 剥皮、铰链、翻页与非刚性变形\|剥皮、铰链、翻页与非刚性变形]] | 开门、翻页、剥皮 | 保可追溯对应 | 可能改形状、曲率和距离 |
| [[3D结构透视研究/方法/07 广义相机、多透视与投影变化\|广义相机、多透视与投影变化]] | 重新分配射线和投影 | 可保世界几何 | 屏幕布局非统一相机 |
| [[3D结构透视研究/方法/08 曲面重采样、解缠与表面展开\|曲面重采样、解缠与表面展开]] | 沿曲线/薄层铺平 | 保特定内在关系 | 不保全部角度/距离 |
| [[3D结构透视研究/方法/09 联动多视窗、切片图册与小图\|联动多视窗、切片图册与小图]] | 多个方向/楼层面板 | 各自投影可保真 | 屏幕面积和跨视图对应 |
| [[3D结构透视研究/方法/10 时间扫描、路径游览与运动视差\|时间扫描、路径游览与运动视差]] | 随时间逐层访问 | 可保原几何 | 非同时可见、记忆负担 |
| [[3D结构透视研究/方法/11 拓扑、语义与几何的混合表达\|拓扑、语义与几何的混合表达]] | 图、层级与几何联动 | 保显式连接 | 抽象丢失形状与距离 |
| [[3D结构透视研究/方法/12 可见性度量与自动显露优化\|可见性度量与自动显露优化]] | 自动选择切口/布局/相机 | 依约束定义 | 代理目标未必等于理解 |
| [[3D结构透视研究/方法/13 感知、评价与失败模式\|感知、评价与失败模式]] | 任务、感知、错误实测 | 定义验证标准 | 结果不能跨任务乱用 |
| [[3D结构透视研究/方法/14 双目、双眼差异与光场硬件\|双目、双眼差异与光场硬件]] | 增加双眼/角向通道 | 可保几何 | 设备要求且仍有遮挡 |
| [[3D结构透视研究/方法/15 物理成像与未知内部数据获取\|物理成像与未知内部数据获取]] | 物理测量和反演 | 真实数据依测量 | 材料、尺度、信号限制 |

## 按你要看清的东西选择

| 目标 | 优先考虑 | 需要防止的误读 |
|---|---|---|
| 一个内部目标在哪里 | 局部剖切 + ghosting + 深度符号 | 目标像浮在外壳上 |
| 每层全部房间有哪些 | 楼层图册 + 可展开层 + 联动3D | 图册缺层、缩小后漏读 |
| 门/楼梯如何连接 | 语义连通图 + 平面图 + 三维高亮 | 投影交叉当成真实连接 |
| 内部构件完整表面 | 层级爆炸 + 局部开合 | 展开距离被当成真实距离 |
| 绕墙角的连续空间 | Graph Camera/多透视 | 屏幕方向与世界方向混淆 |
| 连续弯曲管腔/薄层 | CPR、解缠或展开 | 平面距离当成原空间距离 |
| 未知实体内部 | 合适物理成像 + 不确定度 | 把生成猜测当测量 |

本矩阵为文献综合，具体效果需[[3D结构透视研究/06 评价任务与验收标准|任务验证]]。
