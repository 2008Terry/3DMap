# 可组合方案与研究假设

返回 [[3D结构透视研究/00 3D结构透视研究 Dashboard|研究 Dashboard]]

这些是基于文献的组合假设，尚未建原型或用3DMap验证；先不按当前引擎能力淘汰。共同前提是内部模型足够可靠，且每个房间、门、墙片和连接有稳定ID。

## A. 结构图册：完整检索的基线

同屏放可缩放楼层小图、中央三维结构及楼梯/电梯连通图。点任何房间，其他视图定位同一对象；选择一条竖向连接时，所有相关楼层同步显露。全楼概览可收起家具，只保墙、门、走廊和核心筒。

它最直接满足“所有空间可清点、所有连接可追踪”，但不声称所有墙面同时在三维里无遮挡。候选依据：[[3D结构透视研究/方法/09 联动多视窗、切片图册与小图|联动多视窗、切片图册与小图]]、[[3D结构透视研究/方法/11 拓扑、语义与几何的混合表达|拓扑、语义与几何的混合表达]]、[[3D结构透视研究/来源/proj-17 OGC IndoorGML 2.0 Part 1- Conceptual Model|proj-17 · OGC IndoorGML 2.0 Part 1: Conceptual Model (2025)]]。验收重点为缺层/漏房间、假连接与跨视图定位错误。

## B. 多透视空间：在一张图里绕过墙角

以房间/走廊门户为图，让观看射线向相邻空间分叉或弯折；局部先展示一两个拐角，另有覆盖全翼的模式。地面、门框和边界颜色提示视线何处发生转向，点击后能回到普通原位视图。

这是最直接回应高维观看比喻的激进路线。世界几何可保留，画面统一透视会改变；不该把屏幕上直连的区域当成真实直线。依据[[3D结构透视研究/来源/proj-02 The Graph Camera (Purdue Technical Report 08-005)|proj-02 · The Graph Camera (Purdue Technical Report 08-005) (2008)]]、[[3D结构透视研究/来源/proj-06 An Evaluation of 3-D Scene Exploration Using a Multiperspective Imag|proj-06 · An Evaluation of 3-D Scene Exploration Using a Multiperspective Image Framework (2011)]]、[[3D结构透视研究/方法/07 广义相机、多透视与投影变化|广义相机、多透视与投影变化]]。验收需同时测检索和方位，不能只看多显示了多少。

## C. 建筑开合：楼层拉开，墙片向外翻

楼层如手风琴展开，外墙和部分隔墙像铰链门翻开，核心筒用连接线保留楼层关系。选中某层时局部再展开；模型过高时按总展开范围自动构图，不把层挤到屏幕外。任意展开件都可动画回原位。

这能让内部获得真实屏幕面积，远强于统一alpha。代价是展开态距离与接触失真，铰链还需明确显示是示意操作。依据[[3D结构透视研究/方法/05 层级、紧凑与多透视爆炸图|层级、紧凑与多透视爆炸图]]、[[3D结构透视研究/方法/06 剥皮、铰链、翻页与非刚性变形|剥皮、铰链、翻页与非刚性变形]]、[[3D结构透视研究/来源/tech-16 Onshape Help- Exploded Views|tech-16 · Onshape Help: Exploded Views (2026)]]。验收看完整形状可辨、原位回忆、连接不丢失。

## D. 原位结构透镜：自动切壁，保留外壳参照

选择房间、路径或结构系统后，求出视点前必要的遮挡区域并切掉；外壳剩余部分以淡轮廓保留。楼板保留厚度和切边，目标用清楚的遮挡/深度符号避免浮在外面。透明作为局部过渡，不承担整楼全部显露。

适合定位和保留原始空间，但单个焦点不会让所有对象同时出现。依据[[3D结构透视研究/方法/03 平面、目标驱动与非平面剖切|平面、目标驱动与非平面剖切]]、[[3D结构透视研究/方法/04 局部X-ray与体数据透镜|局部X-ray与体数据透镜]]、[[3D结构透视研究/方法/02 隐藏线、轮廓与语义着色|隐藏线、轮廓与语义着色]]。验收看目标原位、前后/内外判断、切口稳定性。

## E. 系统展开：按连接摊开而非按外观堆叠

楼层、房间、楼梯、电梯、管线系统各有语义层级；展开以邻接和包含为约束，而非把所有部件均匀推远。对弯曲连续结构使用沿路径展开，对薄墙/薄层用表面图册，对房间网用连通图。

它偏向“所有关系能读清”，不会强行把整栋体积套进一张无失真平面。依据[[3D结构透视研究/方法/08 曲面重采样、解缠与表面展开|曲面重采样、解缠与表面展开]]、[[3D结构透视研究/方法/11 拓扑、语义与几何的混合表达|拓扑、语义与几何的混合表达]]、[[3D结构透视研究/方法/12 可见性度量与自动显露优化|可见性度量与自动显露优化]]。验收看图与几何的一致性、哪些度量仍有效，以及展开是否制造假邻接。

## 组合方向

值得比较的是A作为完整检索参照，B/C作为增加同屏显露的实验，D提供原位核对，E负责关系和系统。任何模式都保存同一个结构身份，避免切换后像在看不同建筑。

这是研究建议，不是为了增加五个新的按钮。下一轮可以固定同一栋楼、同一组任务，比较少数候选；在结果出来前不宣称其中某个方案已经最优。

## 数据层先明确

公开的真实楼层图、可靠BIM或实测内部为高可信来源；按楼高估层、通用房间模板和生成补全应明确标近似或示意。真实Burton层数、夹层/地下层定义、Hatcher翼之间的连接都应单独有来源。视觉通透无法补救这些数据错误。
