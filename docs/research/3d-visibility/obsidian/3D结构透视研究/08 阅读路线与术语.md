# 阅读路线与术语

返回 [[3D结构透视研究/00 3D结构透视研究 Dashboard|研究 Dashboard]]

## 最短阅读路线

先读[[3D结构透视研究/来源/cross-01 A Taxonomy of 3D Occlusion Management for Visualization|cross-01 · A Taxonomy of 3D Occlusion Management for Visualization (2008)]]理解遮挡管理空间，再读[[3D结构透视研究/来源/proj-06 An Evaluation of 3-D Scene Exploration Using a Multiperspective Imag|proj-06 · An Evaluation of 3-D Scene Exploration Using a Multiperspective Image Framework (2011)]]了解多透视的实证，接着看[[3D结构透视研究/来源/tech-02 Automated Generation of Interactive 3D Exploded View Diagrams|tech-02 · Automated Generation of Interactive 3D Exploded View Diagrams (2008)]]的层级拆解与[[3D结构透视研究/来源/med-05 ClearView- An Interactive Context Preserving Hotspot Visualization T|med-05 · ClearView: An Interactive Context Preserving Hotspot Visualization Technique (2006)]]的原位局部显露。最后用[[3D结构透视研究/来源/cross-05 Seeing Through the Overlap- The Impact of Color and Opacity on Depth|cross-05 · Seeing Through the Overlap: The Impact of Color and Opacity on Depth Order Perception in Visualization (2025)]]和[[3D结构透视研究/来源/cross-06 Evaluation of depth perception in crowded volumes|cross-06 · Evaluation of depth perception in crowded volumes (2024)]]校正“画出来就看懂”的直觉。

如果关注完整楼层和连接，直接读[[3D结构透视研究/方法/09 联动多视窗、切片图册与小图|联动多视窗、切片图册与小图]]、[[3D结构透视研究/方法/11 拓扑、语义与几何的混合表达|拓扑、语义与几何的混合表达]]；关注像高维一样绕过遮挡，读[[3D结构透视研究/方法/07 广义相机、多透视与投影变化|广义相机、多透视与投影变化]]、[[3D结构透视研究/方法/05 层级、紧凑与多透视爆炸图|层级、紧凑与多透视爆炸图]]、[[3D结构透视研究/方法/08 曲面重采样、解缠与表面展开|曲面重采样、解缠与表面展开]]；关注未知内部怎么获得，读[[3D结构透视研究/方法/15 物理成像与未知内部数据获取|物理成像与未知内部数据获取]]、[[3D结构透视研究/方法/16 单图去遮挡与生成式补全|单图去遮挡与生成式补全]]。

## 容易混淆的术语

| 术语 | 本库含义 | 不应自动等同 |
|---|---|---|
| X-ray / ghosting | 虚拟淡化、隐藏或局部穿视表达 | 实体X射线采集 |
| OIT | 不依赖提交顺序的透明合成方法族 | 所有层人眼可读 |
| depth peeling | 提取有序表面片元的渲染技术 | 用户逐层理解全部体积 |
| opacity peeling | 按累计不透明贡献等规则探索体层 | 固定物理楼层 |
| cutaway | 显示性切掉遮挡区域 | 完整外壳仍可见 |
| exploded view | 部件位姿被展开 | 真实空间距离 |
| unfolding | 特定表面/薄层/拓扑的展开 | 任意三维体积无损铺平 |
| multiperspective | 一张图组合多个观看射线结构 | 一个真实普通相机 |
| occlusion-free | 针对给定目标和约束的显露 | 任意复杂场景无条件全可读 |
| 4D | 可能指3D加时间、射线参数或组成变量 | 四维观察者已实现 |
| all visible | 每个目标获得某种视觉贡献 | all legible / all relationships understood |
| reconstruction / completion | 测量反演 / 先验推断 | 两者具有相同真实性 |

## 继续阅读时记录什么

记录目标结构、所需数据、是否原位、改变哪些不变量、哪些对象没有显示、任务和样本、失败案例，以及证据是否全文。每个新结论至少链接一条原始资料；生成或示意内容始终标状态。
