# 二维屏幕中的三维内部结构可视化研究

研究日期：2026-10-15。研究目标来自用户：全面寻找任何领域中让二维屏幕呈现三维内部结构的方案，先理解方法与取舍，不以现有 3DMap、Qt 或校园场景筛选；整理为 Obsidian 参考数据库。

## 范围与研究问题

1. 已知完整三维数据时，怎样揭示被外壳、其他构件或自身遮挡的结构？
2. 怎样同时保持结构可辨、连接关系可读和原始空间关系可追溯？
3. 需要牺牲什么：遮挡物、原始位置、度量距离、形状、深度顺序、屏幕面积、时间或硬件？
4. 没有内部数据时，物理成像和概率补全分别能获得什么，不能证明什么？
5. 单个目标可见、全部目标可见、全部目标可辨和全部关系可理解，分别有什么证据？

## 检索范围

跨医学影像、科学体数据、工程与装配插图、建筑/BIM/城市、地质、分子/细胞、三维交互、人类知觉、渲染算法、非线性摄影/投影、立体/光场显示、物理无损成像和机器学习恢复。使用作者/实验室、出版社、机构官网、官方软件文档和源代码仓库；搜索引擎、ResearchGate 和二手报道只用于找线索。

从 Elmqvist/Tsigas 的遮挡管理分类出发做前后向线索追踪，再以 2023–2026 年论文补充，避免把老算法说成今年创新。基础论文保留真实年份。检索日期不充当发表日期。无法打开的全文标明访问层级。

## 方法族检查表

- 透明混合与 OIT
- 内外轮廓、隐藏线、Blueprint 和光晕
- 规则与自适应切面、剖开、任意形状裁剪
- 局部 X-ray 与体数据透镜
- 分层/层级/自动爆炸图
- 剥离、开合、非刚性变形与体数据展开
- 多透视、广义相机和投影变化
- 曲面重采样、平面化与低维展开
- 多视窗、切片图册、联动概览与细节
- 时间扫描、路径规划、视差与动态显露
- 拓扑/语义图与几何混合表达
- 可见性与布局自动优化、目标驱动可视化
- 感知评价与失败案例
- 双目、双眼不同透明度、光场与立体硬件
- X-ray/CT、中子、缪子、OCT、GPR 和非视线成像
- 单图去遮挡与生成式补全的真实性边界
